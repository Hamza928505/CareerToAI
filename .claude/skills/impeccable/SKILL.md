# Impeccable Execution
1. **Zero Hallucinations:** Never assume a function or class exists without checking the codebase.
2. **Edge Cases Handled:** Always write defensive code. Handle loading states, empty states, and error states gracefully.
3. **Self-Correction:** If you write code, mentally dry-run it. If an API might fail, wrap it in a try/catch.
4. **No Placeholders:** Never leave // TODO or ...rest of code unless explicitly told to. Write the complete, impeccable solution.
