# Image to Code
When provided with an image of a UI:
1. **Deconstruct Layout:** Mentally break the image into Flexbox/Grid structures before writing code.
2. **Color & Typography Extraction:** Match the visual weight, font sizes, and colors closely using the project's existing design tokens.
3. **Fidelity:** Replicate hover states and active states that are implied by the design.
4. **Integration:** Output standard, maintainable code rather than inline styles.
